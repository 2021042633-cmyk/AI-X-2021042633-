# RealSense 적외선 영상 기반 컵 객체 탐지

AI+X 딥러닝 프로젝트 진행 자료입니다. Intel RealSense D435i의 적외선 영상으로 컵을 촬영하고, YOLOv8n을 학습해 탐지 결과와 오류 사례를 살펴봤습니다.

## 저장소 구성

- `그림(Figure)`: 실험 흐름과 검증 지표 그림
- `데이터(Dataset)`: 클래스, 데이터 분할, 설정 파일
- `모델(Model)`: 모델과 학습 조건
- `실행환경(Runtime Environment)`: 기록된 개발 환경
- `실험결과(Experiment Results)`: 학습 지표와 결과 해석
- `예측시연(Prediction Demo)`: 실시간 탐지 기록과 오류 사례
- `코드(Code)`: 학습·검증·예측 코드 예시
- `Technical Blog.md`: 교수님 가이드에 맞춘 기술 블로그

## 진행 상황

적외선 촬영, 컵 라벨링, YOLOv8n 학습, 이미지와 실시간 화면에서의 탐지 확인까지 진행했습니다. 검증 세트는 3장으로 작고, 손을 컵으로 오인하는 사례가 남아 있습니다. 카메라-로봇 좌표 보정과 실제 그리퍼 파지 성공률 시험은 아직 진행하지 않았습니다.

원본 이미지, 모델 가중치와 일부 실험 화면은 이 진행본에 포함되지 않았습니다. 해당 자료를 확보하면 각 폴더에 추가할 예정입니다. 코드 폴더의 스크립트는 실험 조건에 맞춘 실행 예시이며, 원래 실행했던 코드와 동일하다고 주장하지 않습니다.
