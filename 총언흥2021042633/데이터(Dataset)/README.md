# 데이터셋

- 카메라: Intel RealSense D435i 적외선 스트림
- 라벨 클래스: `cup`
- 초기 분할: 학습 12장, 검증 3장
- 업데이트 분할: 학습 16장, 검증 3장
- 별도의 촬영 그룹은 테스트용으로 남겼습니다.
- `objects4`에서는 손만 보이는 적외선 이미지를 배경 예시로 추가했습니다. 이미지 수는 기록에서 확인되지 않습니다.

연속 프레임이 학습과 평가 데이터에 나뉘어 들어가지 않도록 촬영 그룹 기준으로 분리했습니다. 검증 세트가 세 장뿐이므로 결과는 예비 결과로 봐야 합니다. 원본 사진과 라벨 파일은 이 압축본에 들어 있지 않습니다.
